# Concept Preview Case Boundary

`scene-v1.png` is an interface illustration, not an admitted Method Atlas case.

It deliberately has no `case.json`, reference-speech file, target-speech file, replay bundle, metric, or comparative claim. The public Comparison Lab therefore renders it as `CONCEPT / NOT ADMITTED` and keeps all replay tracks locked.

The asset record is maintained at `apps/web/public/atlas/demo/ASSET_LICENSES.md`. A real case may only be created after video, text and reference-speech rights have each been recorded, its assets hashed, and at least two complete method results bind to the same Case Manifest.
