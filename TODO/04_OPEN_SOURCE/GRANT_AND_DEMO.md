# Grant and Demo Plan

## 申报定位

### 项目名称

`OpenDub：多模态情感可控视频智能配音开源工具`

### 所属方向

`AIGC 应用与工具`

### 项目仓库

`https://github.com/GalaxyCong/OpenDub`

### 当前版本

申报前若完成最小闭环，填写 `v0.1.0-alpha.1`；只有全部首版质量门通过才填写 `v0.1.0`。不得为申报提前虚报稳定版本。

### 开源协议

`Apache License 2.0`。申报材料同时说明模型代码、权重和数据遵循各自许可。

## 申报核心摘要

OpenDub 面向短视频、动画、数字人和在线课程等内容创作场景，建设本地优先的多模态视频配音开源工具。区别于仅依据文本生成语音的传统 TTS，OpenDub 将视频口型、人物表情、场景上下文、授权参考声音和目标时间窗纳入统一配音流程，生成音色一致、情感可控、节奏匹配且可直接回填视频的配音。项目基于团队在 HPMDubbing、StyleDubber、EmoDubber 等视频配音研究与开源实践中的积累，重点完成统一模型适配接口、端到端媒体流水线、情感导演、候选比较、质量评测、Web 工作台和可复现部署，推动研究代码转化为可使用、可扩展、可持续维护的开源工具。

## 申报表栏目映射

### 项目背景

强调三点：

1. 普通 TTS 与真实视频配音在口型时长、角色音色、情感和场景一致性上的差距；
2. 现有研究代码环境、输入和指标分散，创作者难以使用；
3. 团队已有连续研究与开源基础，具备工程化转化条件。

### 主要功能

- 视频与台词导入；
- 授权参考音色；
- 视频感知的时长与韵律条件；
- 情感类别与强度控制；
- 多候选生成和 A/B 试听；
- 统一内容、音色、情感和同步评测；
- 配音轨和成片导出；
- CLI、API、Web Studio 和 Docker。

### 技术架构

按六层描述：

1. 媒体与时间线；
2. 视觉/文本/声音条件；
3. 模型适配器与隔离运行时；
4. 声学与声码器；
5. 统一评测；
6. Web/API/CLI。

### 创新点

写产品与开源工程创新，不声称新论文算法：

- 将视频条件、角色声音、情感和时间窗统一为可扩展接口；
- 将系列视频配音模型组织为能力后端；
- 生成、评测、追溯和视频导出形成一条闭环；
- 许可、权重、输入和指标公开可复现；
- 本地优先和声音授权机制进入默认工作流。

### 社区贡献

如实列出：

- HPMDubbing；
- StyleDubber；
- EmoDubber；
- HPMDubbing_Vocoder；
- 已公开论文、代码、模型、数据处理说明和社区反馈。

必须使用申报时实时核验的 Stars、commit、Issue 和下载数据，不把当前规划阶段的数字写死在 DOCX。

### 兼容适配

- 已验证：填写真实 Ubuntu、Python、CUDA、GPU 和 FFmpeg。
- 计划：Docker GPU、Adapter SDK。
- 国产硬件只有完成真实测试才能移入“已支持”。

### 阶段目标

#### M1：统一基础

- 主仓库、许可证、项目 Schema；
- 媒体导入和时间线；
- Adapter Runtime；
- CLI 基础。

#### M2：真实闭环

- 首个情感配音 Adapter；
- 声码器；
- 候选生成；
- 四类评测；
- 配音轨与成片导出。

#### M3：开源发布

- Web Studio；
- Docker；
- 中英文文档；
- 授权 Demo；
- `v0.1.0` Release；
- HPMDubbing/StyleDubber 后续适配入口。

### 商业化计划

保持克制：

- 核心工具持续开源；
- 面向内容机构提供可选的部署、模型适配、算力优化和工作流集成服务；
- 不以封闭 SaaS 作为种子计划短期目标；
- 不出售或分发未经授权声音。

### 希望支持

- GPU 算力与推理优化；
- 开源合规和模型许可指导；
- 内容创作场景试用；
- 社区传播、开发者活动和外部 Adapter 共建；
- 国产算力适配资源，仅作为后续验证。

## 演示视频制作包

完整导演脚本、镜头表、录制、后期、素材授权和事实核验要求见 [DEMO_FILM](DEMO_FILM/README.md)。该制作包定义一支 2 分 40 秒正式影片，以及 60 秒与 30 秒派生版本。申报视频必须使用正式影片的事实核验表，不得用路线图能力替代已实现功能。

## Demo 制作规范

- 1920×1080，30 FPS；
- 界面缩放保证文字可读；
- 禁止使用版权电影片段；
- 录屏中不出现个人绝对路径、密钥、未公开权重链接和真实邮箱；
- 语音对比响度一致；
- 每个技术声明均可在仓库找到证据；
- 提供带字幕和无旁白版本；
- README 使用 15–25 秒精简 GIF，不嵌入完整高清视频。
