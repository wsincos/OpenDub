# Assets and Rights Checklist

## 原则

每一个进入影片的像素和声音都应当能回答三个问题：它来自哪里、是否可用、是否能公开发布。没有明确来源的素材不得进入正式片。

## 素材登记字段

| 字段 | 内容 |
|---|---|
| Asset ID | 固定标识，例如 `video.actor.arrival.v1` |
| 类型 | 视频、声音、音乐、音效、图标、字体、截图、图形 |
| 文件 | 相对文件路径 |
| 来源 | 自制、授权素材库、开源资源、上游仓库 |
| 权利人 | 个人、团队、素材平台或机构 |
| 使用范围 | 申报、GitHub、路演、社交媒体、商业演示 |
| 许可 | 具体协议/授权书/订单编号 |
| 署名要求 | 需要或不需要，以及具体文案 |
| 期限 | 永久或到期日期 |
| 对应镜头 | Shot ID |
| 校验和 | SHA-256 |

## 必备素材

### 授权演员视频

- 8–12 秒，演员从平静到惊喜；
- 一份肖像和表演授权；
- 一份声音克隆/生成配音展示授权；
- 一份允许在 GitHub、基金申报和公开演示中使用的授权；
- 原始视频、无声视频、环境声和可裁切版本。

### 参考声音

- 同一演员录制；
- 清晰、单一说话人、无背景音乐；
- 记录录制设备、采样率和授权；
- 不使用第三方名人、影视角色或网络抓取声音。

### 台词

首选原创短台词：`你终于来了。`。若扩展示例，台词由团队原创或来自公版文本，并记录来源。

### 音乐与音效

- 使用 CC0、明确商用授权库或团队原创；
- 每一条音乐和音效在项目中标记许可证与署名；
- 不使用影视原声、流行歌曲或来源不明的 BGM；
- 保存授权截图或订单凭据到非公开归档。

### 字体和图标

- 中文：Noto Sans SC 或 Source Han Sans SC；
- 英文：Inter；
- 等宽：JetBrains Mono；
- 图标：Lucide；
- 在片尾或技术说明中保留需要的许可证说明。

### 既有研究素材

HPMDubbing、StyleDubber、EmoDubber 的论文图、仓库截图和公开视频只用于说明研究基础。使用前检查各自许可；不把上游演示视频重新打包成 OpenDub 官方输出。若引用截图，保留仓库 URL、commit 和拍摄日期。

## 屏幕录制脱敏

录制前检查：

- Git 远程 URL 是否只含公开仓库；
- 文件路径是否不含个人目录名；
- 模型下载 URL 是否不含签名 token；
- 浏览器标签、书签、通知是否不含私人信息；
- API 日志、终端和 JSON 是否不含邮箱、电话、密钥或内部服务器；
- 用户上传视频是否已授权公开。

## 片尾鸣谢模板

```text
OpenDub Demo Film
Video and voice performed with permission.
Music and sound effects used under their respective licenses.
Research foundations: HPMDubbing, StyleDubber, EmoDubber.
OpenDub is open source under Apache-2.0.
```

将最后两行改为与实际使用的上游成果一致；未接入的上游仓库标记为 research foundation，不标为 production backend。

## 发布前权利检查

- [ ] 每个镜头都有 Asset ID。
- [ ] 演员的肖像、声音和生成展示授权完整。
- [ ] 每段音乐、音效、字体、图标可公开发布。
- [ ] 没有受限影视数据、未授权电影片段或名人声音。
- [ ] 上游截图和论文图遵循其许可和合理引用要求。
- [ ] 所有署名已写入片尾或发布说明。
- [ ] 授权文件保存在团队受控归档，不公开个人签名信息。
