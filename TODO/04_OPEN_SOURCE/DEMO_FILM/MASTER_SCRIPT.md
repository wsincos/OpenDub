# Master Script

## 使用规则

- 这是 2 分 40 秒正式版的中文旁白与屏幕文字母版。
- 方括号内是制作提示，不朗读。
- 引号内的台词是授权演员素材中的角色台词，不由旁白朗读。
- 每项功能在最终录制前必须通过 `TRUTH_AND_QA.md` 核验；未通过时替换为其中定义的诚实表述。

## 00:00–00:08｜冷开场：声音改变画面

**画面**：演员近景，字幕显示“你终于来了。”先播放普通朗读 2 秒，画面回切起点后播放 OpenDub 确认候选 3 秒。中间以播放头闪切，不用分屏。

**现场声音**：保留两段声音，不加音乐。

**屏幕文字**：

```text
同一句台词。
画面决定它该怎样被说出。
```

**旁白**：无。

## 00:08–00:20｜问题：配音不是朗读

**画面**：同一镜头暂停在演员表情变化帧；台词、嘴部节奏和面部表情以细线标注。

**旁白**：

> 配音从来不只是把文字读出来。角色的表情、口型、场景和时间，都会改变一句话应该有的声音。

**屏幕文字**：

```text
Video dubbing is more than text-to-speech.
```

## 00:20–00:40｜复杂性：让声音理解画面

**画面**：同一段视频冻结，口型 ROI、表情曲线、场景色温、文本音素、参考声音波形依次出现并对齐到时间线。每项出现 1.5–2 秒。

**旁白**：

> OpenDub 将这些条件放在同一条时间线上：看见口型和表情，理解台词的节奏，保留角色的声音，并且让情感可以被直接控制。

**屏幕文字**：

```text
Visual sync · Character voice · Emotion direction · Timeline control
```

## 00:40–01:02｜进入工作台：从素材到角色

**画面**：真实 OpenDub Studio。新建项目，导入视频、SRT 和授权参考声音。资源栏出现项目素材；时间线生成片段；授权状态为已确认。

**旁白**：

> 在 OpenDub 中，视频、台词和授权参考声音首先成为一个可追溯的项目。每一句台词都有自己的角色、目标时间窗和生成记录。

**屏幕文字**：

```text
Video · Script · Authorized voice
```

## 01:02–01:28｜情感导演：同一句话，不同表达

**画面**：选中一个片段。右侧检查器展示角色、参考声音、`neutral`、`happy` 和强度 0.82。生成两个候选。候选列表同时显示，不切出产品界面。

**旁白**：

> 选择角色声音，设定情感和强度，再把目标时长交给模型。系统生成多个候选，让创作者听见差异，而不是猜测参数。

**屏幕文字**：

```text
neutral → happy 0.82
```

## 01:28–01:48｜A/B 证明：让观众自己听

**画面**：候选 A 与 B 轮流播放，各 3 秒。播放器、时间线和波形同步移动。A 是中性或不匹配候选；B 是确认候选。视频画面保持一致。

**现场声音**：只播放候选 A/B，音乐完全退出。

**旁白**：无。

**屏幕文字**：

```text
Candidate A / Candidate B
```

## 01:48–02:07｜可验证：从听感到指标

**画面**：B 候选被确认。检查器展开真实结果：内容、音色、情感、时长四项指标；播放头与目标窗对齐。数字从真实报告中逐项淡入。

**旁白**：

> 每次生成都留下模型、权重、参数和评测记录。内容是否清晰，音色是否一致，情感是否匹配，时间是否对齐，都可以被检查和复现。

**屏幕文字**：

```text
Content · Voice · Emotion · Sync
```

## 02:07–02:25｜开源基础：从研究到工具

**画面**：Studio 的模型能力面板过渡到干净的能力图。EmoDubber、HPMDubbing、StyleDubber、HPM Vocoder 以“Emotion / Visual Sync / Style / Acoustic Rendering”出现。只显示已核验状态；Planned 模型置于淡色路线区。

**旁白**：

> OpenDub 建立在团队持续积累的视频配音研究之上，把情感、视觉同步、风格和声学渲染组织为可替换的开源能力。每个适配器都有清楚的来源、许可和运行边界。

**屏幕文字**：

```text
Open source by design.
```

## 02:25–02:36｜结果：回到画面

**画面**：最终导出的短片完整播放。右下角克制出现 `Rendered with OpenDub` 和真实版本号。人物完成“你终于来了。”的最终候选。

**现场声音**：最终配音与环境声。音乐以很低音量回归。

**旁白**：

> 从一段视频，到一句真正属于画面的声音。
