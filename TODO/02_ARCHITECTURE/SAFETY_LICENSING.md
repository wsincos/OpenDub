# Safety, Licensing, and Responsible Use

## 基本立场

视频配音同时涉及代码许可、模型权重、训练数据、视频版权、声音人格权益和生成内容标识。OpenDub 不能用一个代码仓库的 MIT 许可证推断所有资产都可自由使用。

## 许可分层

### 平台代码

- OpenDub 新增平台代码使用 Apache-2.0。
- `LICENSE` 只覆盖 OpenDub 原创代码。
- `NOTICE` 记录重要上游项目和修改。

### 上游代码

每个适配器维护 `LICENSES.md`，记录：

- 上游仓库 URL；
- 固定 commit；
- 源代码许可证；
- 复制或修改的文件；
- 修改摘要；
- 必须保留的版权声明。

### 模型权重

模型注册表必须单独记录：

- 权重下载地址；
- 权重许可证或使用条款；
- SHA-256；
- 文件大小；
- 适用模型版本；
- 是否允许商业使用；
- 是否需要用户手动接受条款。

许可未知或禁止再分发的权重不得打包进 Docker 镜像和 GitHub Release。

### 数据与示例

- 不在仓库分发受版权保护的电影片段。
- V2C 等受限制数据只提供引用、获取说明和用户自行配置入口。
- 官方示例必须是团队自制、明确授权或许可允许再分发的素材。
- 示例目录包含 `ASSET_LICENSE.md`，逐项说明视频、声音、文本、音乐和图像来源。

## 声音授权

### ConsentRecord

每个参考声音必须绑定：

- 声音提供者标识或“本人录制”声明；
- 授权用途；
- 获取时间；
- 来源；
- 是否允许发布生成结果；
- 声明版本；
- 用户确认时间。

OpenDub 不验证法律真实性，但必须阻止“未确认授权”的参考声音进入生成任务。

默认只记录本地生成许可。只有在“允许分享生成结果”被主动确认后，`ConsentRecord` 才会记录
`allow_generated_output_distribution=true`；该字段是申请影片和可公开示例的额外证据，不能由
模型、项目管理员或导出操作自动推断。

### 禁止默认能力

- 不提供名人、演员或公众人物预置声音。
- 不提供从网络 URL 自动抓取声音。
- 不提供绕过授权检查的隐藏参数。
- 不上传参考声音到遥测或错误报告。

## 生成内容标识

- 渲染清单以 `content_label: "AI-generated dubbing by OpenDub"` 标记生成内容。
- MP4 写入同一非破坏性元数据字段；不保证所有平台保留该元数据。
- `render.json` 记录项目 revision、混音策略、片段 ID、导出位置与 `distribution_authorized`。后者仅在本次导出全部已接受片段的声音授权都明确允许分享生成结果时为 `true`。
- `distribution_authorized=false` 允许本地审听，但不得用于公开示例、申请视频或发布素材；每个候选的 `result.json` 记录生成工具、模型和版本。
- 可选音频水印列为 `v0.3.0+` 研究方向，未实现前不声称具备防伪能力。

## 隐私

- 默认零遥测。
- 诊断包不包含原视频、参考声音、生成音频和完整台词。
- 日志只记录素材 ID、哈希前缀、时长和格式。
- API 日志不记录 multipart 文件内容。
- 删除项目时提供“只删除项目”和“同时清理未共享缓存”两种明确操作。

## 安全

### 文件处理

- 音频和视频上传先写入未登记的临时文件，通过 FFprobe 验证对应流并记录时长；失败文件不会进入项目清单。
- 文件扩展名仅用于安全保存和 FFprobe 提示，不能替代媒体内容验证。MIME 检查尚未实现，不得宣称已具备。
- 不把用户文件名拼入 shell 字符串。
- FFmpeg 使用参数数组调用，不启用 shell。
- 解压模型包时阻止路径穿越、符号链接逃逸和超大解压。
- 下载权重必须验证长度与 SHA-256。

### 服务边界

- 默认只绑定 localhost。
- 远程绑定时启动器显示明确警告，并要求显式 `--allow-remote`。
- 首版远程模式无认证，因此文档明确禁止暴露到公网。
- Web 前端使用受限 CORS，API 限制上传大小和并发任务数。

### 依赖与发布

- CI 生成 Python、Node 和容器 SBOM。
- 使用依赖漏洞扫描和 secret scanning。
- Release 构建来源可追溯，容器使用非 root 用户。
- 模型适配器子进程只获得其工作目录和模型缓存的必要权限。

## 内容风险说明

README、应用首次生成和导出界面应以简洁方式说明：

> 仅使用您拥有或已获授权的视频、文本和声音。请勿冒充他人、误导受众或生成违法内容。您应对输入素材和输出使用承担责任。

产品不使用恐吓式弹窗，也不把法律条款伪装成技术保证。

## 适配器准入审核

适配器升级为 Stable 前必须通过：

1. 源代码许可可识别；
2. 权重条款可识别；
3. 模型输入和输出不触发未声明的外部上传；
4. 示例素材授权完整；
5. 安装与卸载不修改系统包文件；
6. 不要求用户手工替换第三方 site-packages 文件；
7. 不包含硬编码个人路径、密钥或远程凭据；
8. 真实推理测试通过；
9. 模型卡公开限制、语言、数据和已知失败模式。

EmoDubber 当前说明中存在手工替换 Lightning 安装文件的训练步骤。OpenDub 适配不得复用这种安装方式；应通过兼容补丁、配置或封装解决。

## 安全事件响应

- `SECURITY.md` 提供私下报告入口。
- 涉及声音、素材泄漏或远程执行的问题按 Critical 处理。
- 发布修复前不在公开 Issue 暴露可利用细节。
- 修复发布后更新公告、受影响版本、缓解措施和验证方法。
