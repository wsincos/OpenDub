- The cases must stay labeled `Archived research example. Not a fresh OpenDub run.`

- The repository must retain the case manifest, this authorization record, asset hashes, provenance record, and the project contact route in `SECURITY.md` / repository governance files.

## Verification note

This is a project-owner authorization record, not an assertion that a third party has independently audited the underlying copyright chain. It is deliberately public about scope and limitation so an application reviewer can distinguish an authorized historical display example from a reproducible benchmark or a Live inference claim.
