# OpenDub V3 Narrated Evidence Walkthrough

This directory is the independent V3 delivery line. It does not modify the V1 or V2 films.

## What V3 shows

1. The task: a complete method maps video, target text, and authorized reference speech to target speech and dubbed video.
2. A female `TASK ILLUSTRATION`: interactive face/lip overlays, English IPA, illustrated prosody, and illustrated output waveform. It has no case audio or transcript.
3. Eight `Archived research example` clips: the four public artifacts for `human-0` and `animation-1`. Only one panel is active at a time, and its `AUDIBLE:` label, video, and audio source agree.
4. Complete-method selection, Method Canvas, and the Evidence Room. These scenes explain inspection and evidence boundaries, not a fresh run or a benchmark result.

## Source contract

- [source-audio-map.json](source-audio-map.json) is the machine-checked identity contract for V1 narration and every case artifact audio source.
- [narration-map.zh-CN.md](narration-map.zh-CN.md) explains the Chinese synthetic-narration excerpts reused from V1.
- [fact-check.md](fact-check.md) records public claims the film may and may not make.
- `assets/browser-captures/` is generated by `scripts/capture_v3_web_clips.mjs` from the live OpenDub web interface.

## Rebuild order

```bash
npm --prefix apps/web run build
node scripts/capture_v3_web_clips.mjs
.venv/bin/python scripts/verify_v3_audio_map.py docs/grant/video/v3/source-audio-map.json --root . --require-captures
bash scripts/build_v3_narrated_evidence_film.sh
```

The final build must retain the visible `AUDIBLE:` label for each history clip and uses that exact artifact file's `a:0` stream. Narration never overlaps an archived artifact clip.
