# V3 影片事实边界

- V3 的女性画面、IPA、韵律和输出波形均是 `TASK ILLUSTRATION`，用于解释视频配音任务的时序约束；它不属于 `human-0` 或 `animation-1`，不含案例音频、转录或新推理主张。
- `human-0` 和 `animation-1` 都是 `Archived research example`。画廊和影片均不把它们表述为同输入公平比较、Live、Replay 或新的 OpenDub 运行结果。
- 八个案例片段各自只映射到同一案例、同一方法文件的 `a:0` 音频流。画面内 `AUDIBLE:` 标签、浏览器活动面板、声源映射与 FFmpeg 输入必须一致。
- 任何一个案例片段播放时，旁白不叠加；网页中只有活动面板会播放、有声音，其余面板暂停、静音并归零。
- 平台讲解使用 V1 交付视频中已经批准的中文合成旁白音轨。V3 不录制真人旁白、不生成新声线，也不把该旁白称作模型输出。
- HPMDubbing、StyleDubber、EmoDubber 仍作为可选择、可检查的完整研究方法展示；V3 不声称将它们的内部模块拼装为新的第四个模型。
- V3 是独立交付线，写入 `docs/grant/video/v3/`；V1、V2 的成片、清单、哈希与 Git 标签保持不变。
