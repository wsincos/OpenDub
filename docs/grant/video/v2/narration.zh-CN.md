# V2 中文旁白稿

本稿与 `OpenDub_VTTS_Showcase_v2.0.0_CN_EN.srt` 同步。当前交付是“字幕主导 + 明确标示的非语音说明音轨”版本；真实案例段保留原始 GT 音轨。若加入人工旁白，应在案例音频片段降低旁白音量，不能将旁白当作模型输出。

1. 视频配音不是把文本简单朗读出来。
2. 无声画面、目标台词和授权参考语音，共同约束一段目标配音。画面提供时间、表情和环境语境，台词定义要说什么，参考语音限定经授权可使用的声音身份。
3. 因此，口型、表情、环境、音素和韵律需要落在同一条时间线上。
4. 这里展示的是团队提供的真人历史研究案例。GT、HPMDubbing、StyleDubber 和 EmoDubber 保留各自身份；它们不是新的 OpenDub 运行，也不是未经验证的公平排名。
5. 动画案例同样遵循这条边界。
6. OpenDub 的做法不是把不同论文的内部模块拼成一个未经验证的新模型，而是把已有工作保留为完整方法。
7. 用户可以点击查看每种方法的技术路径、组件、可观察信号和来源。
8. 没有可复核的权重、权利和运行记录，OpenDub 不会把方法标为 Live。
9. OpenDub，让视频配音方法可理解、可选择、可准备、可核查。
