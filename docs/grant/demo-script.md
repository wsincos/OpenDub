# OpenDub 申报演示脚本

本脚本用于当前 `v0.0.1-alpha.0` 的申报展示。对应成片、双语字幕和 SHA-256 已交付于 [视频目录](video/README.md)。它的目标是完整呈现“理解任务 -> 选择完整方法 -> 授权项目准备 -> 证据核查”的产品闭环，而不是用未核验的音频制造 Live 生成假象。

## 片长与原则

- 建议时长：95–110 秒；1920×1080、30 FPS；网页录屏保持浏览器 UI 清晰可读。
- 使用自制、公开领域或取得明确授权的视频与参考语音；不出现个人路径、令牌、真实邮箱、未公开权重链接或受限影视素材。
- 每个 Concept 页面保留内容状态标签；不播放测试正弦波、不展示来源不明 Demo、不宣称刚刚生成了新音频。
- 录制前执行质量检查，录制后由未参与制作的人按 [证据索引](evidence-index.md) 复核旁白。

## 时间轴

| 时间 | 画面 | 旁白 / 同期声 | 必须保留的事实边界 |
| --- | --- | --- | --- |
| 00:00–00:10 | OpenDub 标题，进入 `/explore` 的输入-方法-输出仪表板 | “OpenDub 是面向 AIGC 内容生产的多模态智能视频配音开源平台。” | 不说“已经生成这段配音”。 |
| 00:10–00:22 | 点击 Video、Target Text、Authorized Reference Speech；切换 Generated Speech / Dubbed Video | “视频、台词和经授权的参考语音共同约束目标配音。研究输出是目标语音，产品输出才是混流后的配音视频。” | 概念波形/频谱必须可见 `CONCEPT`。 |
| 00:22–00:35 | 进入 `/methods`，切换三个“按首要需求选择”选项 | “我们保留三套完整方法，而不是把不同论文的内部模块拼成一个未经验证的新模型。导览只建议优先理解和准备的方法。” | 不说“自动选择最优模型”。 |
| 00:35–00:50 | 进入一个 Method Canvas；点击 2–3 个组件，操作该方法专属交互 | “每个方法都可点击查看其完整信息流、核心组件和可观察信号。例如，这里说明的是视觉韵律 / 多尺度风格 / 情感引导机制。” | 明确这是机制解释，状态为 `Concept`。 |
| 00:50–01:02 | 点击 `Prepare project`，创建或打开 Studio 项目 | “选择会写入一个带固定证据版本的方法记录，并把所需输入和控制条件带入本地项目。” | 项目中应显示所选方法和 `CONCEPT`，不要打开 Run。 |
| 01:02–01:20 | 导入授权视频和参考语音，添加台词片段；显示输入确认控件 | “OpenDub 先记录项目、时间线和授权输入，再讨论生成。参考声音只在明确授权后进入片段。” | 只用授权素材；情感字段是准备条件，不是已生效的模型控制。 |
| 01:20–01:32 | 点击 Export preparation record，短暂展示导出成功消息或 JSON 关键字段 | “系统重新核验视频哈希、文本指纹、参考语音同意记录和方法一致性，导出可复现的准备清单。” | 清单不是音频生成请求。 |
| 01:32–01:45 | 进入 `/evidence`，显示 `Concept` / unavailable 与准入条件 | “代码、权重、许可、哈希和真实 smoke test 缺一不可。未通过前，OpenDub 不把方法标为 Live。” | 不把缺少 checkpoint 说成“已支持”。 |
| 01:45–01:50 | 回到架构图或项目页，出现仓库地址与结束标题 | “OpenDub 让视频配音方法变得可理解、可选择、可准备、可核查，并为合规的真实运行建立开放入口。” | 结束语不承诺具体上线日期。 |

## 录制前检查

1. 运行 `make check`、`make web-check`、`uv run python scripts/verify_registry.py model-registry/upstreams.yaml` 和 `uv run python scripts/check_docs_links.py`；
2. 用新的临时工作目录启动 API；录屏前刷新浏览器，确认 `/explore`、`/methods`、一个 Canvas、`/studio`、`/evidence` 均能打开；
3. 在 Studio 中预先准备一个仅包含授权输入的项目，或使用全新项目完整录制；
4. 逐项核对 [证据索引](evidence-index.md)，特别检查是否把 `Concept`、准备导出或测试适配器误说成真实生成；
5. 导出后检查字幕、音量、URL 和浏览器窗口中没有个人信息或不应公开的素材。
