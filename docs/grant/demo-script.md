# OpenDub 申报 Alpha 演示脚本

本脚本用于当前 `v0.0.1-alpha.0` 申报阶段的短演示。它替代正式影片中尚未具备证据的真实模型生成镜头；完整 2 分 40 秒正式片仍以 [DEMO_FILM/MASTER_SCRIPT.md](../../TODO/04_OPEN_SOURCE/DEMO_FILM/MASTER_SCRIPT.md) 为准。

## 片长与原则

- 建议时长：75–90 秒；1920×1080、30 FPS。
- 全部素材为自制、公开领域或取得明确授权的素材。
- 不播放测试正弦波并将其表述为配音，不展示未下载或未验证的模型。
- 录屏中不要出现个人路径、令牌、真实邮箱、未公开权重链接或版权素材。

| 00:08–00:20 | 创建 OpenDub 本地项目 | “OpenDub 把视频配音组织成可追溯的本地项目。” | 展示真实 revision |

## 录制前检查

1. 运行 `make check` 与 `make web-check`；
2. 使用全新的临时工作目录，确保录屏中没有其他项目或用户信息；
3. 准备一段可公开再分发的短视频和一段自录音频；
4. 按 [evidence-index.md](evidence-index.md) 逐项核对解说词；
5. 录制完成后由非项目成员检查是否把“规划中”说成“已实现”。
