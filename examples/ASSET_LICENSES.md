# Example Asset Licenses

The repository does not ship copyrighted film clips, recordings of real people, model weights, or
generated dubbing outputs.

`scripts/build_examples.py` creates the example media locally with the installed FFmpeg `testsrc2`
and `sine` filters. The resulting files are synthetic test fixtures created on the user's machine.
They are not captured from third-party media and do not contain a real speaker's voice. The text
cues are original sentences written for this repository and are released under Apache-2.0 with the
rest of the new platform code.
